# Workflows

このディレクトリには、ComfyUI 上で本プロジェクトのノードを利用するためのワークフローを収録しています。

## 推奨ワークフロー

### `minimax_h3_ref2va_integrated_mv_generator.json`

参照画像、楽曲、ボーカル音源及び歌詞から、MiniMax H3 用のミュージックビデオを自動生成する統合ワークフローです。

画像解析、プロンプトのマージとエンハンス、歌詞と音声のシーン分割、MV プランニング、縮小 Markdown の JSON コンパイル、Ref2VA によるシーンの連続生成及び動画の結合までを一つの流れで実行します。通常の生成にはこちらを使用してください。

### `minimax_h3_ref2va_integrated_mv_generator_short.json`

上記の統合ワークフローを短いテスト用素材で確認するための短時間版です。長い楽曲で生成を始める前のモデル、ノード、配線及び基本設定の動作確認に適しています。

## 使用上の注意

- ワークフローが参照する画像、音声及び歌詞は、利用環境に合わせて読み込みノードで選択し直してください。
- GGUF／Vision モデル、MiniMax H3 関連ノード及び各依存カスタムノードが別途必要です。
- 初回は短時間版で一連の処理が完了することを確認してから、通常版を実行することを推奨します。
- `development/` 以下はノードや仕様の開発・検証用です。利用者向けワークフローではなく、動作も保証されません。詳細は [development/README.md](development/README.md) を参照してください。
