# プロンプトの意味・情景保全

2026-09-13。縮小Markdownのコア構文と既存入出力を変えず、翻訳と背景置換で発生する意味の欠落を防ぐ。

## 1. コンパイラ

- `semantic_guard`: `global`（ノード既定）、`all`、`off`。globalはSubject/保持分析/共通、allはショット・音響も監査する。低レベルのtranslate_markdown APIは後方互換のためoffを既定とする。ノードからは必ず設定を渡す。
- 構造、参照タグ、否定、日本語残存を検証した訳文について、同じロード済みLLMへ独立した原文対訳監査を要求する。属性の所有者、形状、寸法、色、個数、部位、比較関係、動作方向、否定の範囲を検査する。
- 日本語・英語の特定単語をPythonで置換しない。判定指示は `common/prompts/semantic_review.txt` に外出しする。
- 1監査は最大4単位。実効コンテキストに収まるまで縮小する。IDごとにPASS/FAILを要求し、欠落・重複・不明ID・出力切断を成功扱いしない。対応バックエンドでは応答構造をGBNFで拘束する。
- FAILの理由を原文の再翻訳へ渡し、失敗単位だけ修復・再監査する。意味修復は最大2回かつretry_max以内。retry_max=-1でも意味修復は有限。監査自体の形式異常は意味不一致と混同せず停止する。
- 同一原文・同一参照の制約は訳文を共有する。Subject導入文は名詞句の契約が異なるため別扱い。類似表現を機械的に同一視しない。日本語の一行一Subject/保持分析を維持する。
- 監査はLLMの判断であり意味一致の数学的保証ではない。offは構造検証のみ。推論増加と誤検出の可能性をUI/利用文書で明示する。

## 2. エンハンサー

- SOURCE分類に `anchor` を追加する。場所、主要な物体・構造物、その色や位置関係の、ユーザー指示と矛盾しない元文をこの分類で保持する。
- Pythonはanchor原文を再生成せず、通常の共通バレット `情景の固定要素: 元文` としてコピーする。新しいMarkdownディレクティブやH3参照タグは導入しない。
- 照明、時間、天候、質感、画像由来の一時的構図はbackgroundとして置換可能。昼の建物を夜へ変更する等の混在文は、ユーザーが変更した属性だけを変更し、物体自体を新BACKGROUNDに保持する。
- 背景detailは描写密度であり場所・物体を消す許可ではない。ユーザーの明示的な場所変更や削除指定は優先する。
- `semantic_guard`は実験的な任意機能としてノード・低レベルAPIとも既定false。8B実測では物体欠落の検出と同時に正しい昼夜変更の誤検出も見られたため、通常ワークフローの停止原因にしない。固定要素の原文コピーは設定に関係なく有効。Trueの場合、候補中に原文がそのまま存在する行はPythonで保持済みと確認し、置換・欠落した行だけを同じLLMで監査する。誤ったSOURCE分類も検出対象とする。
- 背景監査の指示は`common/prompts/environment_review.txt`に分離する。各元行について`EVIDENCE<TAB>id<TAB>元の物体と候補中の対応`、続いて`CHECK`を要求する。原文と候補を隣接するsource/candidateとして渡し、元文を候補の証拠と混同させない。小型モデル向けに元行1件ずつを監査し、候補と権威を省略せずコンテキストに収める。収まらない場合はn_ctxの拡張を案内して停止する。対応バックエンドでは根拠512文字、理由256文字を上限として応答の長文化を抑える。
- 意味検証に失敗した候補を出力しない。再生成は既存retry_max以内、意味不一致は最大2修復で停止する。主体・保持分析・ユーザーバレットを書き換えない。
- 監査根拠の`MISSING`（元の物体が欠落）と`NO_OBJECTS`（元文に物体なし）を区別する。MISSINGを記載してPASSを返す矛盾した応答は受理しない。変更可能な昼夜・天候・照明は固定物体の欠落として検査しない。ユーザー条件の優先と既存の時間帯ガードは維持する。
- passthroughでは従来通り追加推論を行わない。報告JSONにscene_anchors、semantic_review_requests、semantic_guardを含める。

## 3. プランナー

- 共通バレットの固定要素を `planning_brief.scene_anchors` としてバイブル・シーン計画へ渡す。full/light_8b/performanceに共通適用する。
- 共通原文を維持し、最初の要求シーンの最初のショットにも固定要素を確実に提示する。リミッタで途中から始めても同じ。被写体の動作やリップシンクは変更しない。
- 寄りのショットで対象物が画角外になることは許容し、全ショットの構図固定は要求しない。

## 検証

属性の逆転・比較部位の取り違え、失敗だけの修復、有限停止、監査形式不正、重複訳の共有、背景物体の脱落、時間帯だけの変更、ユーザー明示変更、固定要素の初期シーンへの受け渡しを回帰テストに含める。実レンダーの品質検証は処理中のジョブへ干渉せず別途行う。
